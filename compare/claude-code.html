Hermes and Claude Code

Claude Code is Anthropic's coding agent. Hermes is an agent that stays running on your machine. Plenty of people use both, with Hermes handing coding work to Claude Code.

Bottom line

Use Claude Code for focused coding sessions. Add Hermes when you want one memory across projects, jobs on a schedule on your own machine, and any model you like.

When to add Hermes

Keep using Claude Code for

  • Long coding sessions inside one repo
  • Its editor integrations
  • Hooks and plugins built for coding

Add Hermes when you want

  • One memory across every project, in files you can read and edit
  • Jobs that run on a schedule on your own machine
  • Your agent in Slack, Telegram and other chat apps
  • Any model, including a local one

How they differ

FeatureClaude CodeHermes

Using them together

Run Hermes as the agent that's always on, and let it call Claude Code for heavy coding. Hermes passes in the goal and the context it has. Claude Code does the work. What Hermes learns goes back into its memory for next time.

Hermes runs on your machine. It sends data only to the model and services you connect.
