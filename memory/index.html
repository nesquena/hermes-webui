Hermes memory plugins · 2026 guide

Which memory provider should Hermes use?

The eleven most popular memory provider plugins for Hermes Agent, compared on price, hosting, license and published benchmarks, with a straight free pick and paid pick.

Install any of them with hermes plugins install <name> and hermes memory setup. One external provider runs at a time, alongside Hermes's built-in MEMORY.md and USER.md.

🕐 Last verified 11 November 2026
The short answer
Best free and best paid

Weighted by published results, price, license and how well each plugin is maintained.

🆓
Best free

Runs on your own machine or server. No subscription.

  • 1
    Hindsight, self-hosted: MIT, no usage limits, one Docker command. The strongest published results across LongMemEval, LoCoMo and BEAM-10M. Bring any LLM, including a local one.
  • 2
    Honcho, self-hosted: the pick if you want Hermes to learn you. 90.4% on LongMemEval-S with a small model. AGPL.
  • 3
    Cognee, local: Apache-licensed knowledge-graph memory. Also free in the cloud for the first 1M tokens.
💳
Best paid

Managed for you, billed by usage or a flat monthly fee.

  • 1
    Hindsight Cloud: pay as you go with no monthly fee: $10 per 1M tokens retained, $0.75 per 1M recalled. Same engine as the free version.
  • 2
    Honcho Cloud: $2 per 1M tokens stored and free context reads. The cheapest way to get managed user modeling.
  • 3
    Supermemory Pro: $19 a month with $20 of credits included. Best for document search and connectors.

Mem0 is still the biggest project, but since 27 October it sells no self-serve paid plan, only a free plan and custom contracts. Its free plan is generous if you bring your own LLM key. Want memory with no setup at all? Holographic needs no LLM and agentmemory needs no account.

Read the benchmarks with care. Almost every score here is published by the vendor, using its own answer and judge models, so the numbers aren't directly comparable. The few outside re-runs come from competitors: Maximem re-ran Mem0's hosted product on LongMemEval in May and got 73.8%, against the 93.4% Mem0 announced in April (its current claim is 94.4%), and agentmemorybenchmark.ai is run by Vectorize, the company behind Hindsight. LongMemEval and LoCoMo now fit inside a large model's context window, so they're close to saturated. BEAM at 10M tokens can't be stuffed into context, which makes it the most telling test. Provider profiles
The fast version

How each one works, what it costs, and the command that installs it.

🧠
Mem0
Apache 2.0 SDK · mem0ai/mem0 · 68.8K ⭐

An LLM pass extracts facts from each conversation, deduplicates them and stores them for semantic search, with optional reranking. The Hermes plugin runs against Mem0's cloud platform, a Mem0 server you host, or fully in-process with your own LLM and vector store. Since 27 October 2026 Mem0 sells no self-serve paid plan: the free plan covers most solo use if you bring your own LLM key, while graph memory, user profiles and SSO need a custom contract.

Free with your LLM key Cloud + self-host 4 tools
PricingFree: 10K adds and 1K retrievals a month for the first 30 days on Mem0's models, then 50K and 10K with your own LLM key · usage-based billing past that, with a monthly cap you set · custom plans by contract · open-source SDK free to self-host
BenchmarksLongMemEval-S 94.4% · LoCoMo 92.5% · BEAM-10M 48.6% (self-reported; a competitor's re-run of the hosted product scored 73.8% on LongMemEval)
hermes plugins install mem0
Best for: the largest community and a managed fact store. Self-host the Apache-licensed SDK if you want no vendor in the loop.
🔬
Hindsight
MIT · vectorize-io/hindsight · 60.5K ⭐

Retains full conversation turns, resolves entities and relationships into a knowledge graph, and recalls with several strategies at once (semantic, keyword, entity and time). Its reflect tool reasons across everything stored. Runs fully local with an embedded Postgres and any LLM, including open-weight ones, or on Hindsight Cloud with no monthly fee.

Self-host free Local + cloud 3 tools
PricingSelf-host free, MIT, no usage limits · Cloud pay-as-you-go: $10 per 1M tokens retained, $0.75 per 1M recalled, $0.05 per reflect call, no monthly fee · new accounts get $5 of credit
BenchmarksLongMemEval-S 94.6% (own benchmark site) / 91.4% (paper) · LoCoMo 92.0% · BEAM-10M 64.1% (self-reported)
hermes plugins install hindsight
Best for: the strongest all-round published results, free when self-hosted and cheap at low volume in the cloud.
🏛️
OpenViking
AGPL-3.0 · volcengine/OpenViking · 42.0K ⭐

A context database from ByteDance's Volcengine. Memories, documents and skills live in a virtual filesystem (viking://) and load in tiers: a short abstract, then an overview, then full content only when it's needed. That's where the token savings come from. In Volcengine's May 2026 test, adding it to Hermes raised LoCoMo accuracy from 33.4% to 82.9% and cut input tokens by 34% and query time by 66%.

Self-host free Self-host + hosted 6 tools
PricingFree to self-host with your own LLM (Ollama works) · hosted service on Volcengine in China: first 50 files free per database, then from ¥0.01 per hour
BenchmarksLoCoMo with Hermes 82.9% vs 33.4% with Hermes's built-in memory (vendor-run, May 2026)
hermes plugins install openvikingstart openviking-server first
Best for: self-hosted knowledge management and long histories where token cost matters. It's AGPL, so check the license before shipping it inside a product.
🕸️
Cognee
Apache 2.0 · topoteretes/cognee · 33.2K ⭐ (core repo)

An LLM extracts entities and relations into a knowledge graph alongside a vector store, and recall walks both. The Hermes plugin adds remember, recall, forget, recap and code search, and shares memory with Cognee's Claude Code and Codex plugins. Local mode installs about 1 GB of dependencies.

Local free Local + cloud 6 tools
PricingLocal and self-host free · Cloud: free for the first 1M tokens, then $1 per 1M tokens processed, plus $5 a month per extra workspace
BenchmarksBEAM-100K 0.79 · BEAM-10M 0.67 (self-reported; Cognee calls the 10M run exploratory because settings were picked on the scored questions)
hermes plugins install cognee
Best for: memory that's really a graph of people, projects and code, shared across several coding agents.
🔍
Supermemory
MIT apps + SDKs, closed engine · supermemoryai/supermemory · 31.6K ⭐ (apps + SDKs)

Builds a memory graph per user (a profile plus a fact hierarchy) and pairs it with SuperRAG document search and connectors. The Hermes plugin captures each turn, recalls before each turn and re-injects profile facts periodically. The core engine is closed source; a free local server handles up to 10,000 documents.

$5 free credit monthly Cloud + local 4 tools
PricingFree: $5 of credits a month (about 1M memory tokens) · Pro $19/mo with $20 of credits · Max $100/mo · Scale $399/mo with SOC 2, HIPAA BAA and a self-host option
BenchmarksLongMemEval-S 84.6% with GPT-5 answers (self-reported) · 81.6% in a run by competitor Vectorize
hermes plugins install supermemory
Best for: search over lots of documents, and teams that want connectors (Gmail, S3, web crawler) with a flat monthly price.
🧩
agentmemory
Apache 2.0 · rohitg00/agentmemory · 30.3K ⭐

Local memory built for coding agents. It captures sessions automatically and recalls with BM25 keyword search, optional on-device embeddings and a small knowledge graph, with no account or API key. One local server shares memory across 26 coding agents; the Hermes plugin connects to it and adds save, recall and search tools.

Free, no account Local 3 tools
PricingFree and open source, no paid tier (agentmemory.space is an unrelated product)
BenchmarksNo answer-accuracy score yet. Retrieval only: 84.7% recall-all@5 on LongMemEval-S (self-reported)
hermes plugins install agentmemoryrun the agentmemory server first
Best for: one local memory shared by Hermes, Claude Code, Codex and the other coding agents you use.
🗂️
Memori
Apache 2.0 SDK · MemoriLabs/Memori · 17.6K ⭐

Turns chat into structured facts and summaries with project and session attribution, so recall stays short: about 721 tokens per answer in its own LoCoMo test. The Hermes provider uses Memori Cloud only and installs through Memori's own hermes-memori tool rather than the plugin catalog.

Free developer key Cloud only 5 tools
PricingFree key: 5,000 memories created and 15,000 recalled a month · paid production plans start at $60K a year
BenchmarksLoCoMo 87.0% with GPT-4.1-mini answers (self-reported)
hermes-memori installexternal installer, see the Hermes docs
Best for: trying structured, low-token recall on the free key. The paid plans are aimed at enterprises.
👤
Honcho
AGPL-3.0 · plastic-labs/honcho · 8.1K ⭐

Models people, not just facts. Honcho stores messages, reasons about each user in the background, and answers questions about them on demand. Each Hermes profile becomes its own AI peer watching the same user, so a coding profile and a writing profile build separate views of you. Cloud or self-hosted.

$5 + $5/mo credit Cloud + self-host 5 tools
Pricing$2 per 1M tokens stored · context reads free · reasoning queries $0.001 to $0.50 each · new accounts get $5, plus $5 a month with a card on file · self-host free
BenchmarksLongMemEval-S 90.4% · LoCoMo 89.9% · BEAM-10M 40.9% (self-reported, Dec 2025, with the small Claude Haiku 4.5 model)
hermes plugins install honcho
Best for: personal assistants and multi-user gateways where the agent should learn each person's preferences and style.
📝
ReMe
Apache 2.0 · agentscope-ai/ReMe · 3.8K ⭐

From the AgentScope project. Memory is plain Markdown in a workspace folder (daily notes and digests) that you can read and edit, with BM25 recall that needs no embedding model. The Hermes provider recalls before each turn and records after it, in-process or through a local ReMe service. It adds no tools for the model.

Free Local Automatic, no tools
PricingFree and open source · bring an LLM for memory extraction
BenchmarksLongMemEval 89.4% on ReMe's cleaned S split · BEAM-1M 65.0% (self-reported)
hermes plugins install reme
Best for: memory you can open in a text editor, with nothing to sign up for.
🏺
Mnemosyne
MIT · mnemosyne-oss/mnemosyne · 3.6K ⭐

A local SQLite memory layer with vector plus full-text search, episodic consolidation and a temporal knowledge graph, with no cloud at all. It exposes 41 tools to the model, the most of any provider here, covering personas, graph queries, import and export, and diagnostics.

Free Local 41 tools
PricingFree and open source
BenchmarksBEAM-100K 65.2% with a Llama 3.3 70B reader (self-reported; an earlier LongMemEval figure was withdrawn pending a re-run)
hermes plugins install mnemosyne
Best for: power users who want fully local memory with a lot of agent-facing control.
💾
Holographic
MIT · itpartypattaya/hermes-plugin-holographic · 36 ⭐ (plugin repo)

A local SQLite fact store with full-text search, trust scores that learn from your feedback, and Holographic Reduced Representations for algebraic queries: everything about one entity, facts that link several, and contradiction checks. No API keys, no network calls and no LLM required. It used to ship inside Hermes and now installs from the catalog with the same data.

Fully local, free Local only 2 tools
PricingFree
BenchmarksNot published
hermes plugins install holographic
Best for: instant, fully private memory with no accounts and nothing to configure.
📒
Built-in memory
Part of Hermes · MEMORY.md + USER.md · always on

Every Hermes install keeps two small Markdown files: notes the agent writes for itself, and a profile of you. They stay on whichever provider you pick, and an external provider adds to them rather than replacing them. Hermes also mirrors writes to these files into the provider you enable.

Included Local Always on
PricingFree, part of Hermes
LimitsSmall and curated by design; not built for searching long histories
hermes memory statusshows what's active
Best for: a handful of standing facts and preferences. Add a provider when you need recall across months of sessions.
Use case recommendations
Just tell me what to pick

Ranked by fit for each scenario, not by partnership or popularity.

💻
Coding agents

State across long sessions and exact technical recall: file names, ports, error strings.

  • 1
    Hindsight: keyword and entity recall finds exact names; reflect summarizes what happened across sessions.
  • 2
    agentmemory: captures coding sessions automatically and shares one memory with Claude Code, Codex and others.
  • 3
    Cognee: has a code-search tool, and shares memory with its Claude Code and Codex plugins.
📚
Documents and knowledge bases

Indexing a large, growing body of content and pulling the right slice at query time.

  • 1
    Supermemory: SuperRAG handles PDFs, images and audio, with Gmail, S3 and crawler connectors.
  • 2
    OpenViking: filesystem-style hierarchy with tiered loading; ingests URLs and documents.
  • 3
    Cognee: builds a knowledge graph over your documents.
🧑‍💬
Learning the user

The agent should pick up your style, preferences and habits and use them in every session.

  • 1
    Honcho: the only provider here built to model people; each Hermes profile keeps its own view of you.
  • 2
    Supermemory: keeps a per-user profile and re-injects it into the conversation.
  • 3
    Mem0: fact extraction tracks preferences well; its dedicated user profiles need a custom plan.
🔑
No accounts, no API keys

Memory that works the moment it's installed.

  • 1
    Holographic: no LLM, no network, one SQLite file.
  • 2
    agentmemory: keyless keyword search out of the box, optional on-device embeddings.
  • 3
    Mnemosyne: local SQLite with vector and full-text search, zero cloud.
🔐
Privacy and air-gapped setups

Data never leaves your infrastructure.

  • 1
    Holographic: a file on disk with zero network calls.
  • 2
    Hindsight: fully local with an open-weight model; its own decision, rerank and embedding models are open weights too.
  • 3
    ReMe: plain files in a folder, served on 127.0.0.1 or in-process.
🏢
Commercial and enterprise

SSO, audit logs, SLAs and a license your lawyers will accept.

  • 1
    Hindsight: MIT; Enterprise runs in your cloud or on-prem with SSO and up to a 99.95% SLA.
  • 2
    Supermemory: Scale plan adds SOC 2, a HIPAA BAA and a self-host option.
  • 3
    Mem0: Apache-licensed SDK; a custom contract adds SSO, audit logs and on-prem.
Setup
Get started in two commands

Install the plugin from the catalog, then pick it in the setup wizard. Keys go in ~/.hermes/.env, never in chat.

Hindsight (free, local)
hermes plugins install hindsight hermes memory setup # choose local_embedded mode # bring any LLM key, or a local model
Honcho (cloud or self-host)
hermes plugins install honcho hermes memory setup # pick device auth on a headless box # or point baseUrl at your own server
Mem0 (cloud)
hermes plugins install mem0 hermes config set memory.provider mem0 echo "MEM0_API_KEY=your-key" >> ~/.hermes/.env
Supermemory (cloud)
hermes plugins install supermemory hermes config set memory.provider supermemory echo "SUPERMEMORY_API_KEY=your-key" >> ~/.hermes/.env
OpenViking (self-host)
openviking-server init openviking-server hermes plugins install openviking hermes memory setup
What it writes to config.yaml
memory: provider: hindsight # one external provider at a time; # MEMORY.md and USER.md stay on

Full setup and options for every provider: hermes-agent.nousresearch.com/docs/…/memory-providers
