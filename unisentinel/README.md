# UniSentinel (scaffold)

Lightweight, real-time monitoring dashboard for Uniswap protocol — project scaffold created to start development.

Quick start

1. Copy .env.example to .env and set ETHEREUM_RPC_URL
2. Install dependencies: npm install
3. Run in development: npm run dev
4. Open http://localhost:3000

Endpoints

- GET /health — basic health check
- GET /api/alerts — placeholder for alerts

This scaffold contains a minimal Web3Service prototype that subscribes to new blocks. Continue by adding monitors, database, and frontend components.
