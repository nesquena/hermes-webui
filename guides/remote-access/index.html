Access Hermes remotely with a private path

Keep the server reachable only by the people and devices that need it. Network access, WebUI authentication and what the agent can do in your accounts are separate controls.

Sources reviewed November 14, 2026.

Choose the smallest network exposure

For one laptop, use an SSH tunnel. For several devices, a private network is easier. Start with the setup guide for supported connection methods.

A public HTTPS hostname can be useful, but it also creates a public entry point. Configure the access gateway and application authentication before making it reachable.

Understand the bind address

A loopback bind (127.0.0.1, the default) accepts connections only from the same machine. Binding to all interfaces lets any network peer that can reach the port connect, subject to firewall and routing rules. Installing a VPN does not by itself limit who can reach the service; the bind address, the firewall and the VPN’s access rules do.

Set a WebUI password or another supported authentication method, then verify it from a fresh signed-out browser. See the authentication reference for the API’s separate requirements.

Restrict the private route

  • Allow only the intended users and devices to reach the host and service port.
  • Keep unrelated management ports, browser debugging endpoints and vault services off the public route.
  • Use HTTPS unless the connection stays on the machine or inside an encrypted tunnel.
  • Keep certificates, proxy configuration and forwarded-identity settings aligned with the actual hostname and origin.

Verify both allowed and denied access

  1. Confirm the intended device can reach the correct hostname and sign in.
  2. Confirm a signed-out browser cannot read protected sessions or settings.
  3. Test from a device or account that should be denied by the network policy.
  4. Remove the test device’s access and verify that it can no longer connect.

Do not publish access tokens, invite links or screenshots containing secrets when reporting a connection problem. Keep a way to disable the tunnel or gateway without asking the agent to repair its own access.
