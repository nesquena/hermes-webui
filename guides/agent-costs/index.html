What does a self-hosted agent cost?

The software can be free while the work still costs money. Budget for model calls, tools, infrastructure and the time needed to operate it.

Sources reviewed November 14, 2026.

Count the full workflow

  • Model usage: input, output, cache rules and any separate reasoning charges. Agent loops can make many calls for one request.
  • Tools: search, browser hosting, embeddings, memory, media generation and other paid APIs.
  • Infrastructure: a server or local hardware, storage, backups, electricity and network services.
  • Operations: updates, debugging, monitoring, restore tests and reviewing important actions.

Estimate a representative task

Run a small, bounded task and record its actual usage. Add tool and infrastructure costs separately.

For example, 20,000 input tokens at $2 per million and 2,000 output tokens at $10 per million cost $0.06. A repeated agent loop can incur that charge several times. Use current provider prices and inspect billing records for your actual work.

Control recurring and unattended spend

  1. Start with a low-frequency schedule and a stopping condition.
  2. Set provider or project spending controls where available; verify whether an alert is a warning or a hard limit.
  3. Cap retries and stop repeating failures. Review a stuck task before restarting it.
  4. Check usage after the first run and after changing a model, plugin or memory provider.

Local models cost hardware, not tokens

Local inference shifts cost toward hardware, electricity and maintenance. Model file size does not equal runtime memory: context, caches and the serving engine also consume resources. A model that loads may still be too slow for your workflow.

Use the dated models guide to choose a starting point, then measure your actual context size and task. Keep credentials and private data within the data path you intended.
