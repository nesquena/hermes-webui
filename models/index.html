Model guide · November 2026

Choose the right model for your agent

Hermes works with any model. Start with a good everyday one, pay more for the hard jobs, and run one locally when you want it on your own machine.

A good starting point

Everyday work
Claude Sonnet 5.5 or GPT-6.1 Sol. Try both on a few of your own tasks.
Hard problems
Claude Opus 5.5, Claude Fable 5.2 or GPT-6 Astra for difficult coding and reasoning.
Small, frequent jobs
GPT-6 Luna for cheap extraction, sorting and routine text.

Choose by the work you do

Coding and tool use

Test the whole loop: read a file, change it, run a test, explain the result. Good snippets don't mean good tool calls.

Writing and editing

Give each model the same brief and a style sample. Keep the one that leaves you the least editing.

Research and current information

Turn on search or browser tools and ask for sources. A model only knows what it was trained on.

Reasoning and background jobs

Spend on reasoning for planning, debugging and hard analysis. Use a faster model for summaries, titles and extraction.

Compare cost per finished task. One million input tokens plus 100,000 output tokens at $2 / $10 costs $3. An agent run makes many calls, so the token rate alone won't tell you the bill.

Run a model on your own hardware

Ollama and LM Studio serve local models through an OpenAI-compatible endpoint. Start small, check tool calling, then go bigger.

Gemma 4 E2B (gemma4:e2b) is Ollama's quickstart model: about a 7 GB download, and Ollama recommends 8 GB of free VRAM or Mac unified memory.

ollama pull gemma4:e2b

Longer context and parallel requests need more memory. With less VRAM, Ollama uses system RAM and slows down.

A local model keeps the model call on your machine. Search, browser and other tools can still reach the internet. See agent credentials.

Connect your model to Hermes WebUI

  1. Choose a provider in onboarding. Enter its API key or use its login flow. For a local server, choose the self-hosted route and enter its Base URL.
  2. Click Test connection. It checks the URL and loads the model list. Configured only means the URL is saved.
  3. Pick the model and try it. Choose it in the model picker, then send a short message and a simple tool task. If the wizard sends you to hermes model, run that where WebUI runs, then reload.

Local server addresses

Ollama on the same machine
http://127.0.0.1:11434/v1
LM Studio on the same machine
http://127.0.0.1:1234/v1
From Docker Desktop to Ollama on the host
http://host.docker.internal:11434/v1

Inside Docker, localhost is the container itself. Linux Docker Engine needs a host-gateway alias; see the local server setup. No key on your server? Leave it blank.
